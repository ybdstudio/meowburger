# Meow Sakura

Idle tycoon mini game for **TikTok Minis** (native canvas build) in the Meow series: the Meow Burger game (same cats, same menu, same economy) moved into a Japanese sakura restaurant. It runs on the Meow Pizza v4.8 engine.

- Current version: **v1.0.1** (`VERSION` in `src/00_config.js`)
- TikTok App ID / HS Game ID: not set yet. Meow Sakura is a new game, so it needs its own App ID, SDK key and ad units in `src/native/hs-config.json` (Meow Burger's were `7699569778830231573`).
- Save key: `meowsakura.v3` (separate from Meow Burger saves).
- Ads, missions, share and cloud save run through the HS TikTok SDK kit (`vendor/hs-tiktok-sdk-1.0.7`).

## Sakura theme
- Characters are unchanged from Meow Burger (`src/15_staff_sprites.js`, `src/16_more_sprites.js`, `assets/characters/`).
- `src/11_sakura.js`: code-drawn theme pieces (blossoms, paper lanterns, sprigs, pennants, noren curtains, petals).
- Code-drawn restaurant: plank walls with lanterns and sakura sprigs (`30_world.js`), sakura trees (`24_env.js`), yatai stalls with pink roofs, noren and lanterns (`26_stations_code.js`), pink sakura VIP rug and table, pennants, pastel balloon arch (`50_render.js`).
- `tools/sakura_art.py KIT_DIR`: swaps prop/food sprites and the TikTok UI art from the unzipped `meow-jp-full` kit, relettering "Meow Burger" to "Meow Sakura" on the loading logo and popups (font: `tools/fonts/Fredoka.ttf`, OFL).
- `tools/sakura_cat.py`: recolours the kit's cat in the loading / icon / popup art to the player's look (called by `sakura_art.py`).
- `tools/char_fit.py` -> `src/19_char_fit.js`: walk-frame head-height fit and tray-point overrides (keep its remap table in step with `SHEET_REMAP` in `50_render.js`).
- `tests/charstrip.js`: renders a character in 8 directions in the real renderer (`node tests/charstrip.js out.png player 1`).
- `tests/shot.js`: screenshots of the web build for art review (`SAVE=state.json OUT=dir NOHUD=1 node tests/shot.js`; a late-game `state.json` comes from `SAVEOUT=state.json node tests/bot.js`).

## Layout
- `src/00_config.js`: all game data (items, stations, spots, tasks, `CFG.ads`, `CFG.gifts`, `CFG.autoPlay`).
- `src/05_platform.js`: platform layer (storage, lifecycle, ads by placement label).
- `src/10…50_*.js`: drawing, sprites, world, game logic, rendering. `15/16/17/18_*.js` are generated by `tools/*.py`.
- `src/26_stations_code.js`: kitchen stations drawn in code against the walls.
- `src/60_ui.js`, `src/65_minis_ui.js`: DOM UI (web build).
- `src/native/`: `adapter.js` (TikTok runtime shims), `60n_ui_canvas.js` (canvas HUD and popups), `65n_hs.js` (HS SDK bridge: onGive, ads, missions, cloud save).
- `assets/`: UI and loading art, icons. `vendor/`: HS SDK kit (do not edit).
- `tools/`: art pipeline (`matte.py`, `build_chars.py`, `build_env.py`, `build_kit_art.py`…). These read source sheets from absolute paths; see the `art-source` branch.
- `tests/`: `bot.js` (full playthrough), `qa_native.js` (fake TikTok runtime), `qa_minis.js` (web), and others.
- `docs/`: the standard tycoon ad scenario, Meow Sakura build notes (`meow-sakura-build-notes.md`), and legacy Meow Pizza notes.

## Build

```bash
python3 src/build.py            # web: dist/artifact.html, dist/index.html, dist/minis
cp src/native/hs-config.example.json src/native/hs-config.json   # fill in gameId, sdkKey, placements
python3 src/build_native.py     # TikTok native: dist/native + dist/native.hs-dashboard.json
```

`src/native/hs-config.json` is gitignored. The build writes its values into `project.config.json` (appid), `meow-config.js` (appId + HS SDK key) and the dashboard JSON (ad unit IDs). Without it the package is built with placeholders; the game still plays, but ads, missions and cloud save stay off. The TikTok **Client Secret** never goes in this repo.

## Test

```bash
node tests/qa_native.js                                    # 44/44
node tests/qa_minis.js                                     # 42/47 (5 legacy checks fail the same way on Meow Burger v1.6.4)
node vendor/hs-tiktok-sdk-1.0.7/hs-check.mjs dist/native   # 0 fail (capital-letter label warnings are expected)
HTML=dist/index.html node tests/bot.js                     # full playthrough, ~40 min
```

## Upload
Zip the contents of `dist/native` with `game.json` at the zip root. Paste `iaa_config` from `dist/native.hs-dashboard.json` into HS → Ads Config → Edit raw JSON.

See `docs/tycoon-ads-scenario.md` for the ad scenario and `CHANGELOG.md` for history.
